# Initiez-vous au Deep Learning

Cette partie contient mes notes, exercices et expérimentations liés au cours [Initiez-vous au Deep Learning](https://openclassrooms.com/fr/courses/5801891-initiez-vous-au-deep-learning) proposé par OpenClassrooms.

## Objectif

- Expliquer les principes de base des réseaux de neurones artificiels

- Mettre en place un modèle de Deep Learning

- Adapter les paramètres d'un modèle de Deep Learning afin de l’améliorer

## Outils utilisés

- Python 3.14+
- Jupyter Notebooks
- Visual Studio Code (En Local)

- Partie 1 : Identifiez les principes de base des réseaux de neurones artificiels

- Partie 2 : Découvrez les réseaux de neurones adaptés au traitement de séquencesf
